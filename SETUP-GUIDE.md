## Step 4 — Optional: Enable the contribution snake

1. Open your repository and click **Settings**.
2. Open **Actions → General**.
3. Under workflow permissions, enable read and write permissions if required by your workflow.
4. Save the settings.
5. Add a valid contribution-snake workflow under:
   `.github/workflows/snake.yml`
6. Open the **Actions** tab and run the workflow if it supports manual execution.

The workflow must be configured correctly and successfully generate the output before the snake image will appear. Follow the workflow's own documentation for its exact configuration.

## Troubleshooting

### Banner is not displaying
Check that the image URL in `README.md` is valid. If using a local image, confirm that the file exists at the specified path and filename.

### Statistics cards are not loading
External services may be temporarily unavailable or rate-limited. Try refreshing the page later.

### Changes are not visible
Confirm that you committed the changes to the profile repository's default branch, then refresh your GitHub profile.
